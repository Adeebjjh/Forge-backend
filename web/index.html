RAILWAY CLOUD RUNNERBUILT-IN

A workspace in the cloud

Forge's built-in cloud: your own always-on runner on Railway. Deploy once, then it just works.

  1. Tap Deploy on Railway and create the service from your repo — the included Dockerfile starts the runner.
  2. Set a FORGE_TOKEN variable (24+ characters, keep it secret).
  3. Add a Railway volume mounted at /data so your workspace and saved keys survive restarts.

Enter the Railway URL (https://…) and your pairing token. Traffic is encrypted with HTTPS. The app reconnects automatically on launch.

Connect GitHub so the agent can read your repositories and open pull requests.

Use a fine-grained token with Contents (read/write) and Pull requests (write) on the repos you want. It lives in the runner's memory — set GITHUB_TOKEN on Railway to keep it across restarts.
